# 3S-Monitor
In depth monitor for 3rd Strike on Fightcade to detect what values are changed during combos

# How to use
1) Either open a Fightcade window by pressing Test Game, or click on a replay
2) From there, load main.lua as a script and run it
3) On the top left, text should appear with information about the monitor
4) Press P1 start + coin or F1 to toggle the monitor on and off
5) Once the monitor is toggled on, it will begin scanning for what exactly has changed
6) Once it is toggled off, it will save it to a text file that should be in a folder called 'Combo Monitor Logs'
