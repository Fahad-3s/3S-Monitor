# 3S-Monitor
In depth monitor for 3rd Strike on Fightcade to detect what values are changed during combos

# How to use
Either open a Fightcade window by pressing Test Game, or click on a replay
From there, load main.lua as a script and run it
On the top left, text should appear with information about the monitor
Press P1 start + coin or F1 to toggle the monitor on and off
Once the monitor is toggled on, it will begin scanning for what exactly has changed
Once it is toggled off, it will save it to a text file that should be in a folder called 'Combo Monitor Logs'
